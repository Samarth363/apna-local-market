# Apna Local Mart — GitHub Pages

A static HTML/CSS/JavaScript marketplace-style website for Indian folk and traditional crafts, organized across all 36 Indian States and Union Territories.

## Files

- `index.html` — main webpage
- `style.css` — responsive styling
- `script.js` — 36-state craft/product database and site interactions
- `.nojekyll` — tells GitHub Pages to serve the site without Jekyll processing

## Publish on GitHub Pages

1. Create a new **public** repository on GitHub.
2. Upload all files from this folder directly into the repository's root.
3. Make sure `index.html` is in the root (not inside another folder).
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and the `/ (root)` folder, then save.
7. GitHub will provide the Pages URL after deployment.

## Important

This is a client-side static site, so it does not require a server, database, Node.js, or PHP to run on GitHub Pages.

Seller contact information is included only where the expanded database already contains publicly verifiable business contact information. Entries without verified seller details are presented as craft/discovery information rather than invented seller records.
